# EV Charging Network: A Systems Engineering Case Study with Discrete-Event Simulation

> A complete systems engineering treatment of a public EV charging station — from stakeholder needs to a simulation-verified design recommendation.

**Author:** Dhilan Amin

## About this repo:
Built over summer 2026 as a self-directed systems engineering project

---

## Project Summary

This project applies the full systems engineering lifecycle to the design of a
public electric-vehicle charging station, from stakeholder needs through
verification. It develops a Concept of Operations, traceable system requirements,
a system architecture, a weighted trade study comparing charger configurations, a
risk register, and a verification & validation matrix. A Python discrete-event
simulation models vehicle arrivals, wait times, charger utilization, and operating
cost to evaluate design options quantitatively. The result is a defensible
recommendation supported by data and traced end-to-end from need to verified
performance.

---

## Why This Project

Designing a charging station is a small but complete systems problem: real
stakeholders with competing goals, performance requirements, cost trade-offs, and
measurable outcomes. This case study demonstrates systems thinking — connecting a
user need all the way to a verified, data-backed design decision.
